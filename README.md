# WorkSmart AI - AI Workplace Productivity Assistant

An all-in-one AI-powered workplace productivity dashboard designed to eliminate repetitive cognitive work.

## ✨ Features (5 Tools)

1. **Smart Email Generator** - Generates professional emails by tone and purpose
2. **Meeting Notes Summarizer** - Summarizes long meetings into key points & action items
3. **AI Task Planner** - Prioritizes tasks using Eisenhower Matrix (Urgent/Important)
4. **AI Research Assistant** - Researches any topic and provides structured summaries
5. **AI Chatbot Interface** - 24/7 workplace assistant for Q&A

## 🛠️ Tech Stack
- Lovable.ai
